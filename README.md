# Techlog CRM — FastAPI Study Project

This repository documents my progress learning FastAPI through an Alura course. The project is a CRM web application for a fictional company called Techlog Solutions, designed to manage customers and service orders.

## Learning Goals

- Build a backend using Python and FastAPI.
- Practice HTTP methods and web routes.
- Render HTML pages with Jinja templates.
- Store and manage data with SQLite.
- Connect backend functionality to a web interface.

## Technologies

The course project uses:

- **Python**
- **FastAPI**
- **Jinja**
- **Uvicorn**
- **SQLite**
- **HTML, CSS, and JavaScript**

## Prerequisites

- Basic Python knowledge
- Understanding of HTTP methods
- Basic HTML, CSS, and JavaScript
- Familiarity with object-oriented programming in Python

Work in progress. Code and notes will be added as I advance through the course.
